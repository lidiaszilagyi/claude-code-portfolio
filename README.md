# Szilágyi Lídia – AI-alapú fejlesztési portfólió

Egyéni vállalkozóként operatív partnerként segítem ügyfeleimet, erős technikai háttérrel: 2016 óta dolgozom szoftvertesztelőként és tesztautomatizálási mérnökként (többek között az IBM-nél és a Morgan Stanley-nél), ma pedig AI-alapú fejlesztési eszközökkel (Claude, Claude Code) építek működő megoldásokat ügyfeleimnek és a saját vállalkozásomnak: ötletből vagy feladatleírásból indulok, és élesben használt rendszerig viszem.

Ebben a repóban négy munkámat mutatom be. Az ügyfélprojekteknél az ügyfelek nevét, belső azonosítóit, e-mail címeit és minden személyes adatot eltávolítottam.

## Amit ezek a projektek mutatnak

- **Ötletből működő rendszer:** mindhárom fejlesztési projekt egy szóban vagy levélben megfogalmazott igényből indult, a követelmények összegyűjtésétől a tesztelésen át az éles használatig.
- **Rendszerek összekapcsolása:** űrlap → e-mail → táblázat → webalkalmazás → AI API → csapatnak küldött levél / Slack; Google Térkép-alapú távolságszámítás; GitHub → Vercel automatikus telepítés; DNS-beállítás.
- **Hibakeresés:** a dokumentációban leírom a valós hibákat és azok megoldását (pl. Apps Script webalkalmazás-kontextus hibái, e-mail-feldolgozás eltérő formázása).
- **Adatvédelmi szemlélet:** az AI-hívásokból kiszűröm a személyes adatokat, a hozzáférési szinteket a megrendelő igénye szerint tervezem.
- **Tesztelői gondolkodás:** minden rendszerhez várt eredményekkel ellátott tesztforgatókönyvet írok, és az eltéréseket dokumentálom.
